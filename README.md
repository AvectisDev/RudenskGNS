Система автоматизации производственного процесса обслуживания и учета газовых баллонов.

## RFID метки

Notification Mode сервер RFID запускается автоматически через ASGI
(`GNS/asgi.py`) или командой:

```bash
python -m filling_station.management.commands.rfid_utils.feig_protocol
```

Также доступна команда `python manage.py rfid_process`.

Особенности:
- ридеры FEIG сами присылают события на TCP-слушатель;
- конфигурация берётся из таблицы `ReaderSettings` (IP/порт);
- обработка меток и оптических входов идёт напрямую через сервисы Django;
- дубликаты меток фильтруются в памяти процесса;
- статусы в Мириаду отправляются для считывателей 2–6 и 8.

Переменные окружения:
- `RFID_NOTIFICATION_LISTEN_HOST` — адрес слушателя, по умолчанию `0.0.0.0`;
- `RFID_NOTIFICATION_LISTEN_PORT` — порт, по умолчанию `8002`;
- `RFID_TAG_HEX_SUFFIX` — суффикс UID баллона, по умолчанию `e0`.

## Карусели наполнения

Три COM-процесса каруселей работают напрямую с сервисами и ORM Django без
HTTP-запросов к собственному API. Паспорта баллонов передаются от RFID через
атомарные FIFO-очереди Redis `reader_<N>_balloon_queue` (`LPUSH`/`RPOP`).
Повторные запросы контроллеров дедуплицируются в памяти отдельного COM-процесса,
а входящие и исходящие кадры проверяются CRC-16/AUG-CCITT.

Команда `python manage.py carousel_process` запускает карусели 1, 2 и 3.
Настройки каждого процесса задаются отдельными переменными окружения:

- `CAROUSEL_<N>_COM_PORT` — COM-порт; значения по умолчанию: `COM3`, `COM4`, `COM5`;
- `CAROUSEL_<N>_BAUD_RATE` — скорость порта, по умолчанию `9600`;
- `CAROUSEL_<N>_RFID_READER` — RFID-считыватель; по умолчанию `8`, `9`, `10`.

Например, для второй карусели используются `CAROUSEL_2_COM_PORT`,
`CAROUSEL_2_BAUD_RATE` и `CAROUSEL_2_RFID_READER`.
